# Calorie Counter Web Application

A simple and efficient web application built with **Python** and **Django** to help users track their daily calorie intake, monitor nutritional goals, and maintain a healthy lifestyle.

## 🚀 Features

* **User Authentication:** Secure user registration and login system so everyone can manage their personal calorie logs.
* **Food & Calorie Tracking:** Easily add, update, and delete food items consumed throughout the day.
* **Daily Summary:** Calculates total calories consumed and compares them against daily recommended goals.
* **Responsive Design:** Clean and user-friendly interface optimized for seamless use.

---

## 🛠️ Tech Stack

* **Backend:** Python, Django
* **Database:** SQLite (Default Django DB)
* **Frontend:** HTML5, CSS3/Bootstrap
* **Version Control:** Git & GitHub
